OpenGeometry keeps one scene inside the kernel: `WorldGraph`. It is the single place that knows
**where** geometry is, so every spatial question — clash, clearance, 2D projection, export — is
answered from the same transforms.

## Definitions and nodes

A **definition** is geometry stored once. A **node** places it:

```
room ─┬─ storage-wall ─┬─ cabinet-1 ─┬─ top-panel     (definition: cabinet/top-panel)
      │                │             └─ door-left     (definition: cabinet/door-left)
      │                └─ cabinet-2 ─┬─ top-panel     (same definitions, different node)
      │                              └─ door-left
      └─ walls ──────── wall-0                        (definition: wall-0 body)
```

Each node stores its transform **relative to its parent**. A node's world transform is the product
of every transform on the way down from the root, the same model used by IFC
(`IfcLocalPlacement.PlacementRelTo`), USD, and CAD assemblies. Forty identical cabinets store one
set of definitions and forty small nodes.

## One source of truth

The graph is live. `setLocal`, `reparent`, and `removeNode` take effect on the next query or
projection; nothing is copied into a separate snapshot.

When a Three.js scene draws graph content, bind each object with `graph.bind(object, nodeId)`. The
graph then writes that object's matrix. Do not also move the object in Three.js: a bound object
takes its position from the graph only. Objects that are not bound keep ordinary Three.js
behaviour.

## Transform rules

Transforms are rigid with a positive uniform scale. Analytic surfaces stay exact under these
similarity transforms; shear, reflection, and non-uniform scale are rejected instead of
approximated.

## Geometry families

| Family | Stored with | Clash / clearance | Projection | STL / STEP / IFC |
|---|---|---|---|---|
| Analytic (`AnalyticSolid`, `Cuboid`, `Cylinder`, …) | `define` | yes | yes | analytic exporters on `AnalyticSolid` |
| Schema-v1 (`Polygon`, `Sweep`, `Wedge`, …) | `defineLegacy` | refused (`unresolved` / error) | yes | `WorldGraph.exportStl/Step/Ifc` |
