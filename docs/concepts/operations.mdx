---
title: Operations
description: How you transform and combine geometry in OpenGeometry
---

Operations are how you *modify* or *derive* geometry from other geometry.

In OpenGeometry you will typically use:

- **Offset** to create parallel paths and profiles
- **Extrude** to turn a planar profile into a solid
- **Loft** to bridge and cap compatible polygon or coaxial-circle sections
- **Sweep** to move a profile along a path
- **Booleans** to union, intersect, or subtract solids

This page gives you the mental model and points you to the API reference.

## Offset

Use offset operations when you need wall thickness, toolpaths, clearances, or parallel curves.

In TypeScript, offset is exposed as methods on primitives like `Line`, `Polyline`, `Rectangle`, and
`Curve` (for example `line.getOffset(...)`).

Go to the API pages:

- [Offset operation](/api/operations/offset)
- [Line](/api/primitives/line)

## Extrude

Extrusion turns a planar profile into a 3D result by pushing it along a direction (currently the Y
axis in the kernel operation).

In the current Three.js wrapper API, the main entrypoints are:

- `polygon.extrude(height)` for polygon-to-solid workflows
- `Solid.extrude(source, height, options)` when you already have a face-like B-Rep source

Go to the API page:

- [Extrude](/api/operations/extrude)

## Sweep

Sweeps generate 3D geometry by moving a profile along a path. This is useful for rails, pipes,
moldings, and architectural trims.

In the public Three.js layer, the most direct API is usually the `Sweep` shape wrapper:

```ts
const sweep = new Sweep({ path, profile, capStart: true, capEnd: true });
```

Go to the API pages:

- [Sweep operation](/api/operations/sweep)
- [Sweep shape (Three.js wrapper)](/api/shapes/sweep)

## Loft

Use `lower.loftTo(upper)` or `loftPolygonSections([lower, upper])` for two simple planar polygon
sections with equal vertex counts and planar ruled sides. Reversed winding and shifted start
vertices are aligned automatically. Coaxial circular sections remain available through
`AnalyticSolid`'s `coaxialCircleLoft` specialization.

Go to the API page:

- [Polygon loft](/api/operations/loft)

## Booleans

Booleans combine solids or cut one solid by another.

The standalone boolean helpers consume strict analytic BRep v2 solids and return a renderable
`AnalyticSolid` with retained face provenance and analytic exchange support.

Go to the API and concept pages:

- [Boolean operations API](/api/operations/boolean-operations)
- [Booleans concept](/concepts/booleans)
