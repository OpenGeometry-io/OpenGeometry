## What booleans do

Union combines occupied material, intersection retains common material, and subtraction removes the
cutter's occupied material from the host. OpenGeometry applies these operations to strict analytic
BRep v2 solids.

The model keeps surfaces, curves, trims, edge uses, pcurves, shell membership, and face provenance.
Triangles are generated after the operation for rendering and never become the result's authority.

## Inputs and results

Use the binary `booleanUnion`, `booleanIntersection`, and `booleanSubtraction` helpers, or the
corresponding `AnalyticSolid` methods. Every operand must be an `AnalyticSolid`. Public `Cylinder`
and `Sphere` instances satisfy that contract.

The result is another `AnalyticSolid`. Its report contains contacts, coincident ownership, and
one-to-many source-face mappings. Separate solids that touch only at an edge or point remain
separate closed shells.

## Tolerances

The model carries separate geometric, intersection, tessellation, and exchange budgets. Boolean
callers do not override these with a single tolerance. Rebuild an authored solid with the required
accuracy when a different modeling budget is needed.

Changing render deflection changes triangle density only. It does not change intersections, trims,
classification, or topology.

## Failure behavior

The analytic engine does not use a faceted fallback. It returns `AnalyticGeometryError` when:

- the requested surface-family case is not covered (`coverage_gap`)
- an intersection branch cannot be certified within its numerical budget (`unresolved_intersection`)
- topology or required geometry is invalid
- a resource limit is exhausted

Unknown point classification is never treated as outside. Invalid input is never routed to an
approximate bridge.

## Release coverage and explicit limits

The SSI service dispatches every unordered pair of Plane, Sphere, Cylinder, Cone, and ring Torus.
It uses analytic sections where they can be certified and bounded numerical branches elsewhere.
The boolean topology layer covers the released canonical solids, planar multi-loop extrusions,
closed-loop imprints, periodic winding, two-sided curved cutter bands, cavities, disconnected
results, and deterministic identical-body ownership.

The following configurations remain explicit release limits and return a structured error:

- a numerical branch whose conservative UV tube can cross a trim boundary between certified anchors
- a higher-order singularity or tangency that cannot be separated within the intersection budget
- a partial coincident overlap between independently trimmed nonplanar faces outside a canonical fast path
- an arrangement where several open SSI branches cross more than two unrelated trimmed faces and the
  available imprint path cannot prove one closed manifold result
- features, clearances, or cap spans at or below the model's geometric budget
- exhaustion of patch visits, branch steps, Newton corrections, or subdivision depth

These failures preserve the operands and identify `coverage_gap`, `unresolved_intersection`, or
`limit_exceeded`. They never produce a faceted substitute or claim an unverified result.

## Provenance

Each result face records its source entity, body, and face key together with its preserved, split,
cut, or coincident role. Subtraction reverses retained cutter faces where required. The report maps
each input face to all corresponding result faces for the completed boolean.
