## Overview

`Arc` stores one analytic circle edge and its parameter span in strict BRep schema v2. Rendering samples that edge to `deflection`; changing the deflection never changes the model topology.

<Note>
  Initialize `OpenGeometry.create(...)` before constructing `Vector3` or an `Arc`.
</Note>

## Constructor

```ts
const arc = new Arc(options?: IArcOptions);
```

<ParamField path="ogid" type="string" optional>
  Stable entity identifier. Generated when omitted.
</ParamField>

<ParamField path="center" type="Vector3" optional>
  Circle center. Defaults to the origin.
</ParamField>

<ParamField path="radius" type="number" default="1">
  Positive circle radius.
</ParamField>

<ParamField path="startAngle" type="number" default="0">
  Edge start parameter in radians.
</ParamField>

<ParamField path="sweepAngle" type="number" default="2π">
  Signed sweep in radians. Its magnitude must be nonzero and at most one full turn.
</ParamField>

<ParamField path="deflection" type="number" default="0.01">
  Maximum requested chord error for the transient render line.
</ParamField>

<ParamField path="color" type="ColorRepresentation" default="0x00ff00">
  Three.js line color.
</ParamField>

## Methods

`retessellate(deflection)` updates only the render sampling and returns the achieved error and segment count. `getBrepSerialized()` returns the strict v2 wire, while `getBrep()` returns the parsed object. Use `edgeIdForSegment(index)` to map a picked render segment back to the authoritative edge. Call `dispose()` when removing the object.

```ts
import { Arc, OpenGeometry, Vector3 } from "opengeometry";

await OpenGeometry.create({ wasmURL });
const arc = new Arc({
  center: new Vector3(0, 0, 0),
  radius: 2.2,
  startAngle: 0,
  sweepAngle: Math.PI * 1.5,
  deflection: 0.01,
  color: 0x2563eb,
});
scene.add(arc);

arc.retessellate(0.002);
```

A full circle uses one model vertex and one closed edge. The default right-handed frame lies in the XZ plane with Y as its normal.
