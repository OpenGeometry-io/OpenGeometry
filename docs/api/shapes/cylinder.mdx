## Overview

`Cylinder` creates a strict BRep v2 solid aligned to the Y axis. A full cylinder contains one
trimmed cylindrical face and two planar caps. A partial sweep adds two exact radial planes.
Changing render deflection never changes this topology.

<Note>
  Initialize `OpenGeometry.create(...)` before constructing `Vector3` or `Cylinder`.
</Note>

## Constructor

```ts
const cylinder = new Cylinder(options?: ICylinderOptions);
```

### ICylinderOptions

<ParamField path="ogid" type="string" optional>
  Stable entity identifier. Auto-generated when omitted.
</ParamField>

<ParamField path="center" type="Vector3" optional>
  Object center. Defaults to the origin.
</ParamField>

<ParamField path="radius" type="number" default="1">
  Authoritative cylinder radius.
</ParamField>

<ParamField path="height" type="number" default="1">
  Height along the local Y axis.
</ParamField>

<ParamField path="startAngle" type="number" default="0">
  Sector start parameter in radians.
</ParamField>

<ParamField path="sweepAngle" type="number" default="2 * Math.PI">
  Signed sector sweep in radians. A full turn creates a periodic full cylinder.
</ParamField>

<ParamField path="deflection" type="number" default="0.01">
  Maximum requested render chord error in model units.
</ParamField>

<ParamField path="color" type="ColorRepresentation" default="0x00ff00">
  Three.js surface color.
</ParamField>

## Geometry and booleans

`getBrepSerialized()` and `getBrepData()` return the strict schema-version-2 model. Use
`retessellate(deflection)` to replace only the transient GPU mesh. `faceIdForTriangle(...)` and
`edgeIdForOutlineSegment(...)` map picking results back to model topology.

`Cylinder` inherits `union(other)`, `intersection(other)`, `subtract([cutters])`, and
`boolean(other, operation)`. Every operand must be an `AnalyticSolid`; unsupported surface
arrangements return a structured kernel error instead of falling back to a mesh boolean.

Use the normal Three.js `position`, `rotation`, and uniform positive `scale` properties for
placement. Boolean operations and world BRep serialization evaluate that placement exactly.

## Examples

```ts
import { Cylinder, Vector3 } from "opengeometry";

const cylinder = new Cylinder({
  center: new Vector3(0, 1, 0),
  radius: 0.9,
  height: 2,
  deflection: 0.01,
  color: 0xf97316,
});
cylinder.outline = true;
```

```ts
const sector = new Cylinder({
  center: new Vector3(0, 1.1, 0),
  radius: 1.4,
  height: 2.2,
  startAngle: -Math.PI / 4,
  sweepAngle: Math.PI * 1.25,
  deflection: 0.01,
  color: 0x2563eb,
});
```
