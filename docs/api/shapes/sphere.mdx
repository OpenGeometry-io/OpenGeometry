## Overview

`Sphere` creates a strict BRep v2 solid with one spherical face, one periodic seam, and explicit
collapsed pole uses. Render triangles are generated on demand and never become model geometry.

<Note>
  Initialize `OpenGeometry.create(...)` before constructing `Vector3` or `Sphere`.
</Note>

## Constructor

```ts
const sphere = new Sphere(options?: ISphereOptions);
```

### ISphereOptions

<ParamField path="ogid" type="string" optional>
  Stable entity identifier. Auto-generated when omitted.
</ParamField>

<ParamField path="center" type="Vector3" optional>
  Sphere center. Defaults to the origin.
</ParamField>

<ParamField path="radius" type="number" default="1">
  Authoritative sphere radius.
</ParamField>

<ParamField path="deflection" type="number" default="0.01">
  Maximum requested render chord error in model units.
</ParamField>

<ParamField path="color" type="ColorRepresentation" default="0x00ff00">
  Three.js surface color.
</ParamField>

## Geometry and booleans

`getBrepSerialized()` and `getBrepData()` return the strict schema-version-2 model. Use
`retessellate(deflection)` to change display density while preserving the single spherical face.
Picking maps through `faceIdForTriangle(...)` and normals come from `normalAtFace(...)`.

`Sphere` inherits `union(other)`, `intersection(other)`, `subtract([cutters])`, and
`boolean(other, operation)`. Every operand must be an `AnalyticSolid`; the kernel reports missing
coverage or unresolved intersections rather than using a mesh bridge.

Use the normal Three.js `position`, `rotation`, and uniform positive `scale` properties for
placement.

## Example

```ts
import { Sphere, Vector3 } from "opengeometry";

const sphere = new Sphere({
  center: new Vector3(0, 1.1, 0),
  radius: 1.1,
  deflection: 0.01,
  color: 0x0891b2,
});
sphere.outline = true;
```
