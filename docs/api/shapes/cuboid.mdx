## Overview

`Cuboid` is a strict analytic BRep v2 solid. Six plane surfaces, twelve line curves, face trims,
edge uses, and provenance remain authoritative. Three.js triangles are transient output generated
from the requested `deflection`.

Initialize `OpenGeometry.create(...)` before constructing `Vector3` or a cuboid.

## Constructor

```ts
const cuboid = new Cuboid(options?: ICuboidOptions);
```

<ParamField path="ogid" type="string" optional>
  Stable model identifier. It is generated when omitted.
</ParamField>

<ParamField path="center" type="Vector3" default="(0, 0, 0)">
  Center in the cuboid's local coordinates.
</ParamField>

<ParamField path="width" type="number" default="1">
  Positive local X extent.
</ParamField>

<ParamField path="height" type="number" default="1">
  Positive local Y extent.
</ParamField>

<ParamField path="depth" type="number" default="1">
  Positive local Z extent.
</ParamField>

<ParamField path="deflection" type="number" default="0.01">
  Maximum requested world-space tessellation error.
</ParamField>

<ParamField path="color" type="ColorRepresentation" default="0x00ff00">
  Three.js render color; it does not alter the BRep.
</ParamField>

<ParamField path="translation" type="Vector3" optional />
<ParamField path="rotation" type="Vector3" optional />
<ParamField path="scale" type="Vector3" optional>
  Scale must be positive and uniform when evaluated by geometry operations.
</ParamField>

## Geometry and placement

`setConfig()` rebuilds analytic planes and trims. Placement remains on the Three.js object and is
applied once when a boolean or export requests world geometry.

```ts
cuboid.setConfig({ width: 7.2, height: 3.2, depth: 0.28 });
cuboid.setPlacement({
  translation: new Vector3(2, 0, 0),
  rotation: new Vector3(0, Math.PI / 10, 0),
  scale: new Vector3(1, 1, 1),
});
```

Use `getBrepSerialized()` or `getBrepData()` for the local strict v2 model and
`getWorldBrepSerialized()` for the placed model. `retessellate(deflection)` changes only the GPU
mesh. `faceIdForTriangle()` and `edgeIdForOutlineSegment()` map rendered picks back to topology.

Direct v2 freeform conversion is not implemented. `canConvertToFreeform()` returns `false` and
`toFreeform()` reports `UnsupportedAnalyticEdit`.

## Boolean example

```ts
import { Cuboid, Opening, OpenGeometry, Vector3 } from "opengeometry";

await OpenGeometry.create({ wasmURL: "/opengeometry_bg.wasm" });

const wall = new Cuboid({
  center: new Vector3(0, 1.5, 0),
  width: 6,
  height: 3,
  depth: 0.3,
  color: 0x9ca3af,
  deflection: 0.005,
});
const opening = new Opening({
  center: new Vector3(0, 1.2, 0),
  width: 1.2,
  height: 1.5,
  depth: 0.45,
});
const cut = opening.subtractFrom(wall, { deflection: 0.005 });
cut.outline = true;
```
