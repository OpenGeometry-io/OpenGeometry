## Overview

`Opening` is an authoritative six-plane BRep v2 cutter. It extends `Cuboid`, renders its surface
transparent by default, and keeps its topology available for selection, export, and provenance.
`subtractFrom()` runs the in-house analytic boolean engine and returns a new `AnalyticSolid`; it
does not mutate the host or rebuild a triangle BRep.

Initialize `OpenGeometry.create(...)` before constructing `Vector3` or an opening.

## Constructor

```ts
const opening = new Opening(options?: IOpeningOptions);
```

The options are `ogid`, `center`, `width`, `height`, `depth`, `color`, `deflection`, `accuracy`,
`translation`, `rotation`, and positive uniform `scale`. Defaults are a `1 × 1 × 0.2` cutter
centered at the origin.

## Subtract from a host

```ts
import { Cuboid, Opening, OpenGeometry, Vector3 } from "opengeometry";

await OpenGeometry.create({ wasmURL: "/opengeometry_bg.wasm" });

const wall = new Cuboid({
  center: new Vector3(0, 1.6, 0),
  width: 4.4,
  height: 3.2,
  depth: 0.32,
  color: 0xcbd5e1,
});
const opening = new Opening({
  center: new Vector3(0, 1.35, 0),
  width: 1.4,
  height: 2,
  depth: 0.45,
});

const cutWall = opening.subtractFrom(wall, { deflection: 0.005 });
cutWall.outline = true;
```

`setConfig()` regenerates the cutter. `setPlacement()` changes translation, rotation, and scale.
`getBrepSerialized()`, `getBrepData()`, `getWorldBrepSerialized()`, picking mappings, STEP/IFC
exchange, and `retessellate()` are inherited from the analytic solid API.

The boolean report is available as `cutWall.report`. It includes source-to-result face mappings,
cut-face ancestry, contact points, and coincident-boundary status.
