## Overview

Analytic IFC export has two v2 workflows:

- `solid.exportIfc()` writes one IFC4 product directly from the authoritative BRep.
- `solid.prepareIfcExchange()` returns the strict Rust-prepared `AnalyticExchangeBodyV2` used by a
  semantic BIM assembler such as OpenPlans and `openplans-ifc-py`.

Both workflows retain analytic surfaces and curves, actual face/bound orientations, cavities,
general bounded intersection curves, and face provenance. They do not inspect a viewport mesh.

```ts
import { OpenGeometry } from "opengeometry";

await OpenGeometry.create({ wasmURL: "/opengeometry_bg.wasm" });
```

## Direct IFC text

```ts
import { Cuboid } from "opengeometry";

const wall = new Cuboid({ width: 6, height: 3, depth: 0.3 });
const result = wall.exportIfc();

console.log(result.report.schema_version); // 2
console.log(result.text);
```

`result.report` is the same prepared body used to assemble the IFC text. It reports world-metre,
Z-up geometry, revision, quality, exchange error, entities, solid roots, and per-face provenance.
World placement is applied once.

## Semantic exchange

```ts
const geometry = wall.prepareIfcExchange();

const payload = {
  schemaVersion: "2.0",
  elements: [{
    type: "FREEFORM_ANALYTIC",
    id: "wall-1",
    name: "Exterior wall",
    ifcClass: "IfcWall",
    geometries: [geometry],
  }],
};
```

`geometries` is a required nonempty array. This keeps a composite authored element as one semantic
IFC product while retaining every exact body. Semantic openings remain explicit relationships; the
host geometry and opening cutter are both prepared by Rust, while the downstream service creates
the IFC products and relations.

The semantic schema version is exactly `"2.0"`. Schema-v1 payloads, a singular legacy `geometry`
field, compatibility defaults, and faceted fallback are rejected.

## Download direct IFC in the browser

```ts
const blob = new Blob([result.text], { type: "application/x-step" });
const url = URL.createObjectURL(blob);
const link = document.createElement("a");
link.href = url;
link.download = "model.ifc";
link.click();
URL.revokeObjectURL(url);
```
