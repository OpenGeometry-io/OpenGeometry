---
title: STL export (experimental)
description: Tessellate strict analytic BRep v2 solids to binary STL at an explicit error bound
---

## Overview

STL stores triangles, so `AnalyticSolid.exportStl(deflection)` tessellates the authoritative BRep
for export. The generated triangles are transient and do not replace surfaces, curves, trims, or
topology in the model.

Initialize the WASM runtime before constructing geometry:

```ts
import { OpenGeometry } from "opengeometry";

await OpenGeometry.create({ wasmURL: "/opengeometry_bg.wasm" });
```

## Export a solid

```ts
import { Cuboid } from "opengeometry";

const cuboid = new Cuboid({ width: 2, height: 1, depth: 1 });
const result = cuboid.exportStl(0.005);
```

`deflection` is a positive distance in authored metres. Shared edges are sampled once, adjoining
faces reuse those positions, and curved normals come from the analytic supports. World placement,
including positive uniform scale, is applied before tessellation.

## Result

`exportStl()` returns:

- `bytes`: binary STL as a `Uint8Array`
- `report.schema_version`: always `2`
- `report.revision`: the tessellated model revision
- `report.triangle_count`
- `report.requested_deflection`
- `report.achieved_deflection`
- `report.float32_encoding_error`
- `report.quality`: `"tessellated_from_analytic_brep"`

Binary STL stores coordinates as Float32. If tessellation plus Float32 encoding cannot meet the
requested bound, the call fails instead of claiming that tolerance.

## Download in the browser

```ts
const blob = new Blob([result.bytes], { type: "model/stl" });
const url = URL.createObjectURL(blob);
const link = document.createElement("a");
link.href = url;
link.download = "model.stl";
link.click();
URL.revokeObjectURL(url);
```

## Write in Node.js

```ts
import { writeFileSync } from "node:fs";

writeFileSync("model.stl", Buffer.from(result.bytes));
```
