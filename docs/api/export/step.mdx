---
title: STEP export (experimental)
description: Export strict analytic BRep v2 solids to STEP Part 21 text
---

## Overview

`AnalyticSolid.exportStep()` exports the authoritative BRep directly. Plane, sphere, cylinder,
cone, and ring-torus surfaces remain analytic; shared curves, trims, orientations, cavities, and
boolean face topology are retained. Viewport triangles are not read or regrouped.

Initialize the WASM runtime before constructing geometry:

```ts
import { OpenGeometry } from "opengeometry";

await OpenGeometry.create({ wasmURL: "/opengeometry_bg.wasm" });
```

## Export a solid

```ts
import { Cuboid } from "opengeometry";

const cuboid = new Cuboid({
  width: 2,
  height: 1,
  depth: 1.2,
  color: 0x0ea5e9,
});

const result = cuboid.exportStep("metre");
console.log(result.report);
```

The length unit is required to be `"metre"` or `"millimetre"`. Authored coordinates are metres;
the exporter applies the selected conversion once. Positive uniform Three.js placement is applied
once before export. Nonuniform placement is rejected because it would change the analytic surface
families.

## Result

`exportStep()` returns:

- `text`: STEP Part 21 text
- `report.schema_version`: always `2`
- `report.revision`: the exported model revision
- `report.length_unit`: the selected unit
- face, edge, solid, cavity, singular-use, tolerance, quality, and validation statistics

The call fails with a structured analytic geometry error if the model is invalid or its exchange
budget cannot be met. It never replaces unsupported analytic geometry with facets.

## Download in the browser

```ts
const blob = new Blob([result.text], { type: "model/step" });
const url = URL.createObjectURL(blob);
const link = document.createElement("a");
link.href = url;
link.download = "model.step";
link.click();
URL.revokeObjectURL(url);
```
