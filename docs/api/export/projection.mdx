## Overview

OpenGeometry projects geometry placed in a [`WorldGraph`](/api/scene/scene-management) to 2D vector
data with optional hidden line removal. You usually:

1. Create wrapper geometry such as `Cuboid`, `Polygon`, `Solid`, or boolean results.
2. Add it to a `WorldGraph` — `define(...)` for analytic solids, `defineLegacy(...)` for schema-v1
   BReps — and place it with nodes.
3. Call `projectLines(...)` or `projectViews(...)` with the nodes you want drawn.

<Warning>
Projection and hidden line removal are experimental. Output and option shapes may change. If you
hit a limitation or confusing output, reach out on
[Discord](https://discord.gg/9wJpbfgGGA).
</Warning>

## Initialization

```ts
import { OpenGeometry } from "opengeometry";

await OpenGeometry.create({ wasmURL: "/opengeometry_bg.wasm" });
```

## Projection APIs

### projectLines()

Projects the bodies under `items` to a flat `Scene2DLines` payload.

```ts
const { lines } = graph.projectLines(items, camera, hlr, deflection);
```

- `items` — node ids; each node's whole subtree is projected once
- `camera` — `CameraParameters` object (see below)
- `hlr` — optional hidden line removal options
- `deflection` — tessellation tolerance for curved analytic surfaces, in world units (default `0.01`)

### projectViews()

Projects the same items once per view and returns `{ [viewId]: Scene2D }`. Every segment carries
`source_entity_id` (the node id) and `layer`, an AIA code derived from the nearest node `kind`.

```ts
const views = graph.projectViews(items, [
  { id: "iso", camera },
  { id: "front", camera: frontCamera, hlr: { hide_hidden_edges: false } },
], 0.01);
```

## Camera JSON

Cameras follow the kernel `CameraParameters` shape:

```ts
const camera = {
  position: { x: 8, y: 6, z: 8 },
  target: { x: 0, y: 0, z: 0 },
  up: { x: 0, y: 1, z: 0 },
  near: 0.1,
  projection_mode: "Orthographic" as const,
};
```

Supported `projection_mode` values:

- `"Orthographic"`
- `"Perspective"`

## Hidden line removal JSON

Hidden line removal options:

```ts
const hlr = { hide_hidden_edges: true };
```

When `hide_hidden_edges` is `false`, projection behaves more like a wireframe export.

## Example

### Project wrapper geometry to 2D

```ts
import { Cuboid, OpenGeometry, Vector3, WorldGraph } from "opengeometry";

await OpenGeometry.create({ wasmURL: "/opengeometry_bg.wasm" });

const graph = new WorldGraph();
graph.define("box", new Cuboid({ center: new Vector3(0, 1.5, 0), width: 5, height: 3, depth: 2 }));
graph.addNode({ id: "box-1", definition: "box" });

const { lines } = graph.projectLines(
  ["box-1"],
  {
    position: { x: 8, y: 6, z: 8 },
    target: { x: 0, y: 0, z: 0 },
    up: { x: 0, y: 1, z: 0 },
    near: 0.1,
    projection_mode: "Orthographic",
  },
  { hide_hidden_edges: true },
);
console.log(lines.length);
```

## Output shapes

### Scene2D

`projectViews(...)` returns one `Scene2D` per view:

- `name?: string` — the view id
- `segments: ClassifiedSegment[]` — each with `geometry`, edge `class`, `layer`, and
  `source_entity_id`

### Scene2DLines

`projectLines(...)` returns a flat line list:

- `name?: string`
- `lines: Line2D[]`

This form is often easier to post-process for custom exporters.

## Projection behavior

- Orthographic views are the best fit for technical drawings.
- Perspective views are useful when you want a presentation-style outline projection.
- Hidden line removal works from the stored B-Rep topology, not from rendered triangle meshes.
- Hidden edges are resolved per body; bodies do not yet occlude each other.
