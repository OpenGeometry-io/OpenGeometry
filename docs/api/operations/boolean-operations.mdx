## Overview

OpenGeometry booleans operate on authoritative analytic BRep v2 solids. They preserve retained
surfaces and curves, rebuild trims, record face provenance, and tessellate only for rendering.
Faceted and schema-v1 operands are rejected.

Initialize the WASM runtime before constructing operands:

```ts
import { OpenGeometry } from "opengeometry";

await OpenGeometry.create({ wasmURL: "/opengeometry_bg.wasm" });
```

## API

The standalone helpers are binary:

```ts
import {
  booleanUnion,
  booleanIntersection,
  booleanSubtraction,
} from "opengeometry";

const union = booleanUnion(a, b, options);
const common = booleanIntersection(a, b, options);
const cut = booleanSubtraction(a, b, options);
```

Every operand must be an `AnalyticSolid`, including the public analytic `Cylinder` and `Sphere`
wrappers. Raw JSON and schema-v1 shape wrappers are not accepted.

`AnalyticSolid` also exposes `union(other)`, `intersection(other)`, and array-only
`subtract(cutters)`. Multiple subtraction cutters are applied in order:

```ts
const cut = wall.subtract([door, window], {
  deflection: 0.005,
  color: 0x10b981,
});
```

## Options

<ParamField path="deflection" type="number" optional>
  Chord-error bound used to tessellate the returned solid. It does not alter the boolean model.
</ParamField>

<ParamField path="color" type="THREE.ColorRepresentation" optional>
  Surface material color for the returned solid.
</ParamField>

<ParamField path="opacity" type="number" optional>
  Material opacity for standalone helper results.
</ParamField>

<ParamField path="transparent" type="boolean" optional>
  Enables or disables material transparency for standalone helper results.
</ParamField>

<ParamField path="side" type="THREE.Side" optional>
  Three.js material side for standalone helper results.
</ParamField>

<ParamField path="outline" type="boolean" optional>
  Shows analytic feature edges. Standalone helpers default this to `true`.
</ParamField>

## Result

The helpers return an `AnalyticSolid`. Use:

- `result.getBrepSerialized()` for strict schema-v2 model JSON
- `result.report` for operation, contacts, coincident ownership, and input-to-result face mappings
- `result.faceIdForTriangle(...)` and `result.edgeIdForOutlineSegment(...)` for picking
- `result.retessellate(deflection)` to change render density without changing topology
- `result.exportStep(...)`, `result.prepareIfcExchange()`, or `result.exportIfc()` for analytic exchange
- `result.dispose()` when removing the result permanently

## Structured errors

Kernel failures throw `AnalyticGeometryError`. Its `code` identifies failures such as
`coverage_gap`, `unresolved_intersection`, `invalid_topology`, or `limit_exceeded`.
`coverage_gap` also exposes the unsupported surface-family pair through `families`.

```ts
import { AnalyticGeometryError } from "opengeometry";

try {
  const cut = booleanSubtraction(host, cutter);
  scene.add(cut);
} catch (error) {
  if (error instanceof AnalyticGeometryError) {
    console.error(error.code, error.families, error.message);
  }
}
```

An unresolved or unsupported analytic case is an error. The API does not fall back to a mesh
boolean or turn an unknown classification into outside.

The cuboid fast paths include aligned planar arrangements, perpendicular cylindrical through-holes
and blind pockets for union, intersection, and subtraction, the complementary cylinder-minus-cuboid remnants, and sphere/cuboid intersections
that cross exactly one cuboid face. The spherical
path returns an exact circle trim and spherical cap for union, intersection, and either subtraction
order. Cases crossing
multiple cuboid faces continue through later intersection coverage and currently return
`coverage_gap`.

## Example

```ts
import * as THREE from "three";
import {
  AnalyticSolid,
  OpenGeometry,
  Sphere,
  Vector3,
  booleanSubtraction,
} from "opengeometry";

await OpenGeometry.create({ wasmURL: "/opengeometry_bg.wasm" });

const scene = new THREE.Scene();
const host = new AnalyticSolid({
  kind: "cuboid",
  width: 4,
  depth: 2,
  height: 3,
  deflection: 0.01,
  color: 0x9ca3af,
});
const cutter = new Sphere({
  center: new Vector3(0, 1.5, 0),
  radius: 0.8,
  deflection: 0.01,
});

const result = booleanSubtraction(host, cutter, {
  deflection: 0.005,
  color: 0x10b981,
  outline: true,
});
scene.add(result);
```
